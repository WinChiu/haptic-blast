# Haptic Navigator

Haptic Navigator is a mobile-friendly React application that provides map-based navigation with optional haptic guidance.
Users can search for locations, plot routes, and enter a navigation mode with clear distance and time indicators.

This project includes:

- A custom Leaflet map UI with a dark theme
- Search with geocoding (Nominatim)
- Walking-route generation (OSRM)
- Navigation mode with live distance + ETA
- Haptic calibration and directional guidance overlay
- Mobile-first layout and UI components
